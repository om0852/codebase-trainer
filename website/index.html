Prerequisites & System Requirements

ENVIRONMENT REQUIREMENTS

Codebase Trainer is engineered to operate 100% locally on your machine without external cloud dependencies, API subscriptions, or telemetry tracking. Ensure your development environment meets the following specifications:

⚡

Node.js Runtime

Node.js 18.0.0+ (LTS Recommended)

Built with ES Modules ("type": "module"). Supports Node.js 18.x, 20.x, and 22.x LTS releases. V8 engine optimizations are utilized for fast BM25 token vectorization.

📦

Package Manager

npm v8.0+, pnpm v7+, or Yarn v1.22+

Supports zero-install execution via npx codebase-trainer, global binary registration via npm i -g, or fast pnpm workspaces.

💻

Operating System

macOS, Linux & Windows (WSL2/CMD)

Full cross-platform support for macOS (Apple Silicon M1/M2/M3 & Intel), Linux distributions (Ubuntu, Debian, Fedora, Arch), and Windows 10/11 (PowerShell, Command Prompt, and WSL2).

🐙

Version Control

Git 2.20.0+

Utilized by the Git Miner engine to extract commit conventions, git blame metadata, change impact paths, and PR review summaries automatically.

Installation Methods

4 DEPLOYMENT MODES

Choose the installation strategy that best fits your workflow. Zero-installation via npx is recommended for instantaneous setup.

Zero-Installation Execution (Recommended)

Run instantly in any repository without globally modifying your Node.js environment:

Global NPM Package Installation

CLI BINARY

Install the cb-trainer executable globally across your system:

TERMINAL

# Verify global CLI installation
cb-trainer --help

# Run CLI commands directly

Docker Containerized Deployment

ISOLATED CONTAINER

Run Codebase Trainer inside an isolated Docker container with mounted local volumes:

TERMINAL
# Build local Docker image
docker build -t codebase-trainer:latest .

# Run MCP server inside container linked to your project
docker run -i --rm -v "$(pwd):/workspace" codebase-trainer:latest mcp

Build from GitHub Source

Clone the open-source repository, install dependencies, and build locally:

TERMINAL

cd codebase-trainer

npm link

IDE Integration & MCP Setup

STEP-BY-STEP CONFIG

Connect Codebase Trainer directly to your favorite AI-powered code editor via the Model Context Protocol (MCP).

Cursor IDE Integration

  1. Open Cursor IDE and navigate to Settings → Features → MCP.
  2. Click + Add New MCP Server.
  3. Set Name to codebase-trainer and Type to command.
  4. In the Command field, enter: npx -y codebase-trainer mcp.
  5. Or edit .cursor/mcp.json directly in your workspace:
.cursor/mcp.json
{
  "mcpServers": {
    "codebase-trainer": {
      "command": "npx",
      "args": ["-y", "codebase-trainer", "mcp"]
    }
  }
}

Antigravity IDE Integration

  1. Locate your global Antigravity config file at %USERPROFILE%\.gemini\config\mcp_config.json (Windows) or ~/.gemini/config/mcp_config.json (macOS/Linux).
  2. Add the codebase-trainer entry under mcpServers:
mcp_config.json
{
  "mcpServers": {
    "codebase-trainer": {
      "$typeName": "exa.cascade_plugins_pb.CascadePluginCommandTemplate",
      "command": "npx",
      "args": ["-y", "codebase-trainer", "mcp"],
      "env": {}
    }
  }
}

Claude Code CLI & Claude Desktop Integration

  1. For Claude Code CLI, run: claude mcp add codebase-trainer -- npx -y codebase-trainer mcp.
  2. For Claude Desktop, open %APPDATA%\Claude\claude_desktop_config.json (Windows) or ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) and paste:
claude_desktop_config.json
{
  "mcpServers": {
    "codebase-trainer": {
      "command": "npx",
      "args": ["-y", "codebase-trainer", "mcp"]
    }
  }
}

Frequently Asked Questions & Troubleshooting

SOLUTIONS & FAQ

Q: Do I need to pay for any cloud subscription or API tokens?

No! Codebase Trainer runs 100% locally on your Node.js runtime. There are zero API keys required, zero third-party cloud servers involved, and zero subscription costs.

Q: How does Codebase Trainer save 99.98% of AI prompt tokens?

Instead of feeding thousands of raw files into your LLM prompt window (which wastes millions of tokens and causes context overflow), Codebase Trainer feeds precise AST facts, Okapi BM25 ranked chunks, and call graphs directly to the agent. This reduces prompt token usage from ~450 million tokens down to ~86,000 tokens for 100 queries!

Q: What should I do if my IDE says "MCP Server connection failed"?

Verify that Node.js 18.0.0+ is installed and accessible in your system's PATH. If running npx -y codebase-trainer mcp fails, try running npm i -g codebase-trainer globally first, then set the command in your IDE to cb-trainer with args ["mcp"].

Q: Where is the codebase index stored?

The codebase index is stored locally inside your project directory at .codebase/ (index.db.json, conventions.yaml, results.sarif). You can add .codebase/*.db.json to your .gitignore if desired.
