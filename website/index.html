IDE Integration & Live MCP Resources

STEP-BY-STEP CONFIG

Connect Codebase Trainer directly to your favorite AI-powered code editor via the Model Context Protocol (MCP) and unlock 14 native tools plus 5 live URI resources.

Cursor IDE Integration

  1. Open Cursor IDE and navigate to Settings → Features → MCP.
  2. Click + Add New MCP Server.
  3. Set Name to codebase-trainer and Type to command.
  4. In the Command field, enter: npx -y codebase-trainer mcp.
  5. Or edit .cursor/mcp.json directly in your workspace:
.cursor/mcp.json
{
  "mcpServers": {
    "codebase-trainer": {
      "command": "npx",
      "args": ["-y", "codebase-trainer", "mcp"]
    }
  }
}

Antigravity IDE Integration

  1. Locate your global Antigravity config file at %USERPROFILE%\.gemini\config\mcp_config.json (Windows) or ~/.gemini/config/mcp_config.json (macOS/Linux).
  2. Add the codebase-trainer entry under mcpServers:
mcp_config.json
{
  "mcpServers": {
    "codebase-trainer": {
      "$typeName": "exa.cascade_plugins_pb.CascadePluginCommandTemplate",
      "command": "npx",
      "args": ["-y", "codebase-trainer", "mcp"],
      "env": {}
    }
  }
}

Claude Code CLI & Claude Desktop Integration

  1. For Claude Code CLI, run: claude mcp add codebase-trainer -- npx -y codebase-trainer mcp.
  2. For Claude Desktop, open %APPDATA%\Claude\claude_desktop_config.json (Windows) or ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) and paste:
claude_desktop_config.json

Frequently Asked Questions & Troubleshooting

SOLUTIONS & FAQ

Q: Do I need to pay for any cloud subscription or API tokens?

No! Codebase Trainer runs 100% locally on your Node.js runtime. There are zero API keys required, zero third-party cloud servers involved, and zero subscription costs.

Q: How does Codebase Trainer save 99.98% of AI prompt tokens?

Instead of feeding thousands of raw files into your LLM prompt window (which wastes millions of tokens and causes context overflow), Codebase Trainer feeds precise AST facts, Okapi BM25 ranked chunks, local dense vector embeddings, and call graphs directly to the agent. Furthermore, the v1.3.0 AST skeletonizer compresses source files by 52%–85% by stripping implementation bodies while preserving interface signatures.

Q: How does the Cross-Service API Contract Drift Detector work?

The drift engine parses frontend client calls (e.g., fetch(), axios.get(), api.post()) and correlates them with indexed backend route controllers across Express, Fastify, Next.js, and NestJS. It flags endpoint 404s, HTTP method mismatches (e.g. GET vs POST), and missing query/body parameters in ~18 milliseconds.

Q: What should I do if my IDE says "MCP Server connection failed"?

Verify that Node.js 18.0.0+ is installed and accessible in your system's PATH. If running npx -y codebase-trainer mcp fails, try running npm i -g codebase-trainer globally first, then set the command in your IDE to cb-trainer with args ["mcp"].

Q: Where is the codebase index stored?

The codebase index is stored locally inside your project directory at .codebase/ (index.db.json, conventions.yaml, results.sarif, dashboard.html). You can add .codebase/*.db.json to your .gitignore if desired.
